# Runforge Dashboard

Дашборд для просмотра запусков AI-агентов. Проект выполнен в рамках тестового задания Junior Frontend Developer.

**Демо:** [https://curious-tapioca-2e428d.netlify.app/](https://curious-tapioca-2e428d.netlify.app/)

## Технологии

- React 19 и TypeScript;
- Vite;
- React Router DOM — синхронизация поиска, фильтра и сортировки с URL;
- Vitest и React Testing Library;
- CSS без UI-фреймворков.

## Возможности

- Список запусков с названием, репозиторием, веткой, статусом, датой и длительностью.
- Поиск по названию запуска и репозиторию.
- Совместная работа поиска и фильтра по статусу.
- Сортировка по дате и длительности. Запуски с неизвестной длительностью остаются в конце списка.
- Модальное окно с метаданными, логами и результатом запуска.
- Состояния загрузки, ошибки с повторным запросом и пустого результата.
- Управление с клавиатуры, возврат фокуса после закрытия модального окна и базовая поддержка скринридеров.
- Адаптивная раскладка для мобильных экранов от 360 px.

## Требования

- Node.js **22.22.2 или новее в ветке 22**, **24.15.0 или новее в ветке 24**, либо **26.0.0+**.
- npm 10 или новее.

Версия Node.js указана с учётом требований `jsdom@31`, используемого тестовой средой.

## Установка и запуск

```bash
npm install
npm run dev
```

Vite запустит локальный сервер на `http://localhost:3000`.

## Проверки

Запустить все автотесты:

```bash
npm test
```

Проверить TypeScript и собрать production-версию:

```bash
npm run build
```

Запустить линтер:

```bash
npm run lint
```

Предварительный просмотр production-сборки:

```bash
npm run preview
```

## Тестовые данные и обработка ошибки

Данные возвращает локальный mock-сервис `src/services/mockApi.ts`. Сервис возвращает Promise с задержкой, чтобы состояние загрузки было заметно. Ошибка загрузки обрабатывается в `App.tsx`; сценарий ошибки и повторного запроса проверяется автотестом через отклонённый Promise.

## Ручная проверка интерфейса

1. Откройте список и убедитесь, что отображаются все четыре статуса.
2. Введите часть названия или репозитория и проверьте результаты поиска.
3. Выберите статус и убедитесь, что поиск и фильтр применяются одновременно.
4. Откройте запуск клавишами Enter или Space, проверьте логи, закройте Escape.
5. Измените параметры и проверьте, что `search`, `status` и `sort` отражаются в адресной строке.
6. Проверьте пустое состояние, сброс параметров и отображение на ширине 360 px.
