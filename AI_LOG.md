# AI_LOG (Отчет об использовании ИИ)

**Инструмент:** ChatGPT (модель GPT-4o)
**Подход:** ИИ использовался в роли ментора и ревьюера. Ассистент помогал проектировать архитектуру, находить ошибки и разбираться со сложными концепциями (React Hooks, TypeScript, A11y).

### Удачные запросы и контекст:
1. **Архитектура:** «Предложи структуру компонентов для списка с поиском и фильтрами». Ассистент предложил разделить интерфейс на `RunList`, `RunItem`, `SearchBar`, `SortSelector`. Это сильно упростило поддержку кода.
2. **Работа с URL:** «Как синхронизировать фильтры с URL в React?». Ассистент показал использование `useSearchParams` из `react-router-dom`. Это помогло реализовать бонусное задание (сохранение фильтров в ссылке).
3. **Тестирование:** «Как настроить Vitest для React-компонентов и замокать асинхронный сервис?». Ассистент дал шаблон настройки `vite.config.ts` и код моков.

### Ошибки и как я их исправлял:
1. **TypeScript:** Ассистент предложил `new Promise(...)`, но TypeScript сообщил об отсутствии типов. Я добавил дженерик `<Run[]>`, и ошибка ушла.
2. **Правила линтера (React 19):** Линтер выдал предупреждение `set-state-in-effect`. Ассистент предложил вынести асинхронную загрузку в `useCallback`.
3. **Доступность:** во время проверки выяснилось, что для модального окна недостаточно обработчика Escape. Я добавил начальный фокус, удержание фокуса внутри диалога и возврат фокуса после закрытия.
### Дополнение после финального ревью

В ходе дополнительной проверки с ChatGPT (GPT-6) были внесены следующие улучшения:
1. **Доступность модального окна:** начальный фокус переводится на кнопку закрытия, клавиша Tab удерживает фокус внутри диалога, после закрытия фокус возвращается на элемент, открывший окно.
2. **Поиск и история браузера:** ввод поискового запроса обновляет текущую запись истории, чтобы кнопка «Назад» не проходила по каждому введённому символу.
3. **Сортировка:** запуски без известной длительности перемещаются в конец списка при обоих направлениях сортировки.
4. **Доступные подписи:** добавлены label для поиска, aria-pressed для фильтров и дополнительные атрибуты модального окна.
5. **Проверки:** добавлены тесты на поиск по репозиторию, совместную работу поиска и фильтра, пустое состояние, ошибку и повторный запрос, управление фокусом и сортировку без длительности.
6. **Документация:** README дополнен требованиями к Node.js, командами запуска, тестирования и сборки, а также описанием структуры проекта.
